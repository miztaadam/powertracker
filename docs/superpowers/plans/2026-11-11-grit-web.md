# Grit Web Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Build Grit as an installable, offline iPhone web app (PWA) with full parity with Android Grit.
It runs the same Kotlin coach code, compiled to JavaScript.

**Architecture:**
- `:domain` becomes Kotlin Multiplatform (JVM and JS). Android consumes the JVM target.
- A `@JsExport` facade exposes plain-data functions to a React + TypeScript + Vite app in `web/`.
- The web app stores data in IndexedDB through Dexie, works offline through a service worker, and is
  deployed to Vercel as static files.

**Tech Stack:**
- Kotlin 2.4.21 Multiplatform and kotlinx-datetime.
- React 18.3.1 + TypeScript (strict) + Vite.
- Dexie 4 and dexie-react-hooks.
- vite-plugin-pwa (Workbox).
- Vitest + Testing Library + fake-indexeddb.
- Playwright.

**Spec:** `docs/superpowers/specs/2026-11-11-grit-web-design.md` (and the Android spec it references).

## Global Constraints

- The Android app must stay green after every task:
  `./gradlew :domain:allTests :app:testDebugUnitTest :app:assembleDebug`.
- Android storage formats are unchanged: Room keeps dates as epochDay Long and weekdays as 1–7. The backup
  format stays version 1.
- Domain dates are `kotlinx.datetime.LocalDate` / `DayOfWeek`. No `java.time` in `:domain`. Nothing in
  `:domain` reads the clock; `today` is always passed in.
- The facade only passes plain data across the JS boundary:
  - ids are `Int`, kilograms are `Double`;
  - dates are ISO `"YYYY-MM-DD"` strings, weekdays are `Int` 1–7 (Monday = 1);
  - enums are their Kotlin `name` strings;
  - advice payloads are the Android `AdvicePayload` JSON string.
- The generated JS domain package is **committed** at `web/src/domain/generated/`, so Vercel builds need no
  JDK. `./gradlew :domain:checkWebDomain` fails if it is stale.
- Web:
  - TypeScript `strict`; no `any` in `src/`, except `src/domain/generated`;
  - every npm dependency pinned to an exact version at least two weeks old;
  - no runtime network requests except Grit's own origin;
  - CSP `default-src 'self'`; fonts and images self-hosted.
- The IndexedDB database is named `grit`. Every schema change is a numbered Dexie version with an upgrade
  test, and a safety copy is written before any upgrade.
- User-visible strings match Android where the feature exists, for example:
  - "No advice right now. Keep logging."
  - "This backup is from a newer version of Grit."
  - "This file isn't a valid Grit backup."
  - "Replace all data?"
  - "Update ready — tap to refresh"
  - export file name `grit-backup-YYYY-MM-DD.json`.
- Look: `docs/design/DESIGN.md` tokens (dark default, light follows the system), Barlow / Barlow
  Condensed (OFL) with tabular numerals, the icon from `docs/design/logo/b-barbell-grey-*`.
- iPhone:
  - `viewport-fit=cover` with safe-area insets;
  - touch targets ≥ 48 px;
  - inputs ≥ 16 px, numbers use `inputmode="decimal"`;
  - no overscroll bounce in the shell.
- Commits end with the session attribution lines.

## Rulings made while planning

- **P1:** the container has only Chromium for Playwright (no WebKit), and the rules forbid installing other
  browsers. E2E therefore runs in Chromium with iPhone 13 viewport and touch emulation, using
  `executablePath: '/opt/pw-browsers/chromium'` when the pinned `@playwright/test` doesn't find it.
  Real-Safari checks are listed as owner manual checks in Task W14.
- **P2:** routing uses a small hash router (`#/today`, `#/coach`, `#/progress`, `#/plan`, `#/settings`,
  `#/lift/:lift`). It works offline from any start URL and needs no server rewrites.
- **P3:** each web table's primary key is an auto-increment number (fits the facade's `Int` ids). The
  built-in exercises keep their seed ids.

## Review Focus

1. **A real Android export file restores on the web, and a web export restores on Android**, with no lost
   fields: miss points, null RPE, failed sets, advice payloads, plan order, baselines, rest alert. Tests in
   W2 and W6.
2. **App killed or reloaded mid-session.** On reopening, the same session shows with every logged set and
   the editor values intact. Tests in W8 and W14.
3. **A Dexie upgrade throws.** The data is untouched, and recovery mode offers the safety copy. Test in W5.
4. **Dates around midnight and in time zones away from UTC.** "Today" is the device's local date, and ISO
   strings never shift a day. Tests in W3 (facade) and W8.
5. **The coach gives identical output on JVM and JS for the same history.** Tested in W3 with a shared
   golden scenario run on both targets.
